Important Info

1. One-Way Communication
This editor sends MIDI commands TO the pedal. It does not read the current knob positions FROM the pedal. What you see on screen is your "Preset State".

2. Cloud Syncing
Presets are strictly saved to your browser's local storage by default. Login with Google (top right cloud icon) to backup your library to the cloud. On browsers where the Google popup can't open (e.g. iOS Web MIDI browser apps), use Login with Email instead: enter the same email as your Google account, then copy the emailed link (check spam!) and paste it into this browser's address bar.

3. Auto-Sync
Once logged in, enable Auto-Sync in the cloud menu to automatically backup your changes as you make them.

Note: Web MIDI requires a secure context (HTTPS) and a supported browser (Chrome, Edge, Opera).
